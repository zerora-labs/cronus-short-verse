# Changelog

All notable changes to CronusShortVerse will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Galaxy Engine v4 procedural textures (solar flares, planet bands, comet ice, black hole accretion disk)
- Collision-safe node layout with force-directed positioning
- Planet rings orient toward orbit center star

## [0.1.0] - 2026-08-21

### Added
- User authentication (register / login / JWT)
- Universe CRUD with fork and chronicle export
- Character CRUD with 5 celestial types (star, planet, comet, meteor, black hole)
- Relationship management (attraction, repulsion, orbit, collision)
- Proposal + voting system with majority auto-approval
- Arc & episode management (CRUD)
- Event tracking (signal / noise)
- Change history with universe filtering
- Galaxy Engine interactive Canvas star map with evolution markers
- Tab-based universe detail page with all management UIs
- Production deployment support (Dockerfile, Nginx, PM2)
- Seed script with test universe "星陨王朝"
- Bilingual documentation (English + Chinese)
